Alpha character cleanup

Method: built-in image_gen edits, followed by ImageMagick alpha-mask refinement.
Original images: textures/Characters/Backups/Alpha-before-cleanup/ (excluded from Godot imports with .gdignore).
Updated images: textures/Characters/Alpha/Usami-chan.png, Takane-chan.png, Kurako-chanpng.png, Koumi-chan.png.
All outputs are transparent RGBA PNGs, normalized to the original 1248x1824 canvas dimensions.

Initial prompt (issued separately for each filename):
Use case: background-extraction. Edit target: the supplied [filename] character sprite. Finish removing its background. Remove ALL disconnected colored background speckles, neon red/blue/cyan/purple/green background remnants, colored fringe and halo outside the character silhouette, border artifacts, and ALL ground shadows or colored platforms below the feet. Make every background region genuinely transparent, including gaps between limbs, hair strands, ears, fingers, wings and clothing. Preserve the original character artwork as exactly as possible: same face, expression, body, pose, hair, ears/wings, outfit, colors, linework and shading. Keep all legitimate character colors including bright green hair/dress or red jacket/tie; remove only background contamination. Preserve the input framing, character size and position and full canvas aspect ratio; do not crop, resize the character within the canvas, redraw, redesign or add elements. Clean antialiased silhouette, no white/black matte, no glow, no text. Output one transparent PNG character cutout.

Second prompt (issued separately for each filename):
Use case: background-extraction. Edit target: this partially cleaned transparent anime sprite, [filename]. This is an EDGE DECONTAMINATION and ALPHA MATTE REPAIR request. The background is already mostly transparent but the silhouette is BAD: fuzzy speckled neon and white halos, isolated red/yellow/green/blue dots, ragged outlines and residual chunks attached to the character. Remove ALL these remaining artifacts. Follow the character's true dark ink outline and replace everything outside that contour with alpha zero, even when the noise color matches hair or clothes. Especially clean around hair tufts, under arms, between legs, around shoes and between fingers. There must be NO scattered dots, NO colored cloud outside contours, NO white crust, NO fringe. Produce a smooth clean continuous illustrated silhouette with subtle antialiasing only at the actual outline. Keep the face, pose, clothing, ears/wings, hair shapes, character details and colors intact; don't redesign the character or change the composition. Remove shadow remnants below shoes. Output a genuinely transparent PNG, retaining full-body framing and all intentional thin hair strands. Prioritize a clean inked silhouette over preserving contaminated edge pixels.

Final edge-restoration prompt (issued separately for each character):
Repair the silhouette of this character sprite. RE-INK AND REBUILD the outer 5 to 15 pixels of the silhouette with clean smooth dark outline and a precisely fitting transparent alpha channel. You MUST REMOVE the existing jagged bright white, red, yellow, green, magenta frayed pixel crust around every outline. These are defective background pixels, not part of the character. Do NOT copy that crust. Locally reconstruct the narrow edge strip where needed to eliminate it. Keep the character interior visually identical, same pose, face, clothes, colors, anatomy and all ears/wings/hair/boots details. Keep full-body composition. Clean polished professional anime game cutout with perfectly smooth outlined edges, no speckles, no fringe, no glow, no shadow. Every pixel beyond the smooth ink silhouette is fully transparent. This is edge restoration, not merely clearing the already empty background.

Selected output: first pass for Usami, final pass for Takane, Kurako, and Koumi.
The AI results still contained edge contamination. Final alpha refinement thresholded the alpha channel at 70%, opened it with Disk:3, eroded it with Disk:2, and softened the alpha with a 0.5-pixel Gaussian blur. RGB artwork was retained from the selected edit. Results were inspected against light and dark backgrounds.
AI editing can alter small artwork details; the original images remain available in the backup directory.
